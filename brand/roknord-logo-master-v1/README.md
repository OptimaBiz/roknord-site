# Мастер-логотип РОКНОРД v1

Это отдельный векторный комплект. Сайт и пакет айдентики не изменены.

## Главные файлы

- `roknord-master-light.svg` — основной прозрачный вектор для светлого фона.
- `roknord-master-inverse.svg` — бело-бирюзовый вектор на `#12362E`.
- `roknord-master-light.pdf` и `roknord-master-inverse.pdf` — векторные PDF для печати и передачи подрядчикам.
- `roknord-master-transparent-6000px.png` — крупный прозрачный PNG.
- Монохромные SVG/PDF — для однокрасочной печати.

SVG и PDF содержат реальные контуры букв, а не встроенный PNG. Геометрия восстановлена из исходного `public/images/brand/roknord-logo-transparent.png`. Цвета: основной `#121316`, акцент `#5BF5C2`, инверсный фон `#12362E`.

## Шрифт

Wordmark является графическим знаком с переведёнными в контуры буквами. Для его использования шрифт не требуется. Название исходной гарнитуры в репозитории не зафиксировано.
